# ROUMUGATE（労務門）

**2024年4月改正 労働条件通知書（変更の範囲・更新上限・無期転換）・固定残業代有効性3要件・月60時間超50%割増＆36協定（2〜6ヶ月80h平均）ブラウザ完結監査ツール**

- 公開URL（GitHub Pages）: `https://pecopeko.github.io/roumugate/`
- オフライン・ゼロ外部通信（100% クライアントサイド ESM）

## 主な機能
1. **2024年4月改正 労基法施行規則第5条準拠チェック**: 就業場所・業務内容の「変更の範囲」、有期契約の「更新上限」「無期転換申込機会・転換後条件」の記載漏れを即時検出します。
2. **固定残業代（みなし残業）最高裁3要件監査**: 基本給との明確区分・時間数の明示・超過額の別途支給合意を判定します。
3. **月60時間超 1.50倍割増（中小企業適用義務）＋最低賃金＋不足差額計算**: 時給換算の最低賃金チェックと固定残業代の不足精算額を1円単位で算出します。
4. **36協定 特別条項 12ヶ月全移動平均チェック**: 月45時間超の回数（年6回上限）・年間720時間・単月100時間未満・複数月（2〜6か月）移動平均80時間超を全区間検証します。
